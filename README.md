# SpreadJS 성과 분석 대시보드 (Performance Analysis Dashboard)

SpreadJS를 활용하여 구현한 **성과 분석 대시보드(Performance Analysis Dashboard) 샘플**입니다.

JavaScript 스프레드시트 컴포넌트인 **MESCIUS SpreadJS**를 사용하여 주요 성과 지표와 데이터를 웹 애플리케이션에서 분석하고 시각화할 수 있는 대시보드를 구현할 수 있습니다.

본 샘플에서는 성과 데이터를 스프레드시트 형태로 구성하고, 주요 지표와 차트를 활용하여 성과 현황을 한눈에 확인할 수 있는 웹 기반 대시보드를 제공합니다.

## 주요 기능

- SpreadJS 기반 웹 스프레드시트 구현
- 성과 데이터 조회 및 분석
- 주요 성과 지표(KPI) 표시
- Excel과 유사한 데이터 분석 화면 구성
- 수식 및 데이터 계산
- 차트를 이용한 성과 데이터 시각화
- Excel 파일 가져오기 및 내보내기
- SpreadJS 파일(`.sjs`)을 이용한 대시보드 저장 및 로드

## 샘플 파일

| 파일 | 설명 |
| --- | --- |
| `성과 분석 대시보드.xlsx` | 성과 분석 대시보드 Excel 템플릿 |
| `성과 분석 대시보드.sjs` | SpreadJS에서 사용하는 성과 분석 대시보드 파일 |
| `샘플코드` | SpreadJS를 이용하여 대시보드를 구현하는 JavaScript 샘플 코드 |

## SpreadJS란?

**SpreadJS**는 웹 애플리케이션에서 Excel과 유사한 스프레드시트 기능을 구현할 수 있는 JavaScript 스프레드시트 컴포넌트입니다.

셀 편집, 수식, 차트, 테이블, 조건부 서식, Excel 파일 가져오기/내보내기 등 다양한 스프레드시트 기능을 제공하며, 웹 기반 업무 시스템에서 Excel 형태의 데이터 분석 화면이나 대시보드를 구현하는 데 사용할 수 있습니다.

성과 분석뿐만 아니라 다음과 같은 업무 시스템을 구현하는 데 활용할 수 있습니다.

- KPI 및 성과 관리
- 경영 성과 분석
- 매출 및 실적 분석
- 데이터 분석 대시보드
- 경영 보고서
- 업무 현황 모니터링
- Excel 기반 업무 시스템의 웹 전환

## 성과 분석 대시보드

이 샘플은 기존 Excel 기반의 성과 분석 업무를 **SpreadJS 기반 웹 스프레드시트 대시보드**로 구현하는 방법을 보여줍니다.

기존 Excel에서 관리하던 성과 데이터를 웹 애플리케이션에서 조회하고 분석할 수 있으며, 수식과 차트를 활용하여 주요 성과 지표와 데이터의 변화를 시각적으로 확인할 수 있습니다.

이를 통해 기존 Excel 기반의 성과 분석 및 보고 업무를 웹 기반 시스템으로 전환하거나, 경영 정보 시스템 및 업무 시스템에 Excel과 유사한 데이터 분석 기능을 추가할 수 있습니다.
